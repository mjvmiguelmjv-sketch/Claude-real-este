# Kit de Motor de Contenidos — Zeno Bank

Un sistema de contenido orgánico + pago, listo para ejecutar, para atraer a comercios
pyme cripto-fluidos a Zeno Bank (zenobank.io), construido sobre un único diferencial
que la competencia no puede copiar: **un founder visible y responsable — Hugo Pino — y
transparencia radical.**

## Para quién es esto
Pequeñas y medianas empresas cripto-conscientes (e-commerce, SaaS, productos digitales,
comercios transfronterizos) que **ya entienden** cripto y están perdiendo margen por
comisiones de tarjeta, chargebacks (contracargos), tipo de cambio y bloqueos de cuentas
por parte de las pasarelas tradicionales.

## Canales
- **Orgánico principal:** TikTok + Instagram (Reels primero, carruseles para guardados).
- **Apoyo:** YouTube (Shorts reutilizados + formato largo para búsquedas de alta intención).
- **Adquisición:** Meta Ads (Instagram/Facebook).

## Dirección actual (Iteración 2)
- **Canales:** Instagram + YouTube + **Meta Ads**. TikTok despriorizado (`02` queda como opcional/repurposing).
- **Mercado:** español. España (primario) + **LATAM núcleo: Venezuela, Perú, Argentina** (`00b` Segmento D).
- **Meta Ads:** conversión-first bajo **Andromeda**, creativo que autofiltra, optimizando por
  conversión/lead, no por CPC (`12`).
- **Conversión:** sistema **comment-to-DM** ("comenta X → DM") + Click-to-Message (`11`).
- **Objeción central:** "no me fío del 0,1%" → se vence con transparencia (`14`).

## Innegociable: Guardrails de cumplimiento
Zeno es una pasarela legítima y **todo lo que se recibe se declara.** Los dolores del
cliente sobre "impuestos" y "la agencia tributaria" se abordan **únicamente** mediante
educación pro-cumplimiento (cómo declarar correctamente los ingresos en cripto, llevar
libros listos para auditoría). **Nunca** posicionamos Zeno como herramienta para evitar
o evadir impuestos ni para ocultar ingresos. El "sin KYC" se comunica estrictamente como
*alta rápida y sin fricción* — jamás como forma de ser invisible ante las autoridades.
El contenido fiscal siempre lleva la nota: "esto no es asesoramiento fiscal — consulta a
un profesional colegiado". Consulta la checklist completa en `00-strategy-master.md` y
aplícala a cada activo antes de publicar.

## Convención de IDs de activos
Cada guion/activo tiene un ID (p. ej. `SF-03`, `CR-02`, `AD-V-04`, `FV-05`) para que el
calendario pueda referenciar piezas reales y ejecutables. Los IDs son estables — reutilízalos
en tu programador de publicaciones y en las etiquetas UTM.
